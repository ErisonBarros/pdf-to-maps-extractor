# pdf-to-maps-extractor
Extrair coordenadas planas (UTM), geodésicas (GMS/Graus Decimais) e caminhamentos perimétricos (Azimutes/Rumos e Distâncias) de documentos PDF nativos ou rasterizados, reconstruindo a geometria analítica validada para exportação em formatos SIG (GeoJSON, KML/KMZ, Shapefile, DXF) e visualização interativa em mapas web.
